# Lingye 首页与制造能力表述优化设计

## 目标

在保留现有首页结构、已选工厂图片和产品分类的基础上，让 Lingye 对外呈现为铝型材定制与采购项目的可靠对接方。工厂场景继续作为重要的视觉信任元素，但页面不再明确宣称 Lingye 自有工厂、自有生产线或所有工序均在自有厂内完成。访客仍能快速浏览产品并提交项目询价。

## 已确认的定位边界

- 强化工厂、生产场景及制造资源的视觉呈现，不在首屏突出“外贸中间商”身份。
- 文案可描述铝型材产品、定制需求沟通、制造资源协调和出口订单支持；具体工艺、质检、产能、认证、交期等只在现有事实可验证时表述。
- 不使用会将合作生产资源误述为 Lingye 自有资产的表达，包括 “our factory”“factory-direct”“in-house production”“自有工厂”“厂内生产”等。
- 对通用行业知识中“manufacturers”的讨论不做机械替换；只处理指向 Lingye 自身的归属或身份声明。
- 保留已有 URL 路径和 slug，尤其包含 manufacturer/factory 关键词的 SEO 路径；本期调整页面内容和 metadata，不引入 URL 迁移或重定向。

## 范围

### 首页

- 保留现有三张工厂轮播图及视觉风格，统一轮播标题和说明的品牌定位，避免每张图切换时切换成不同身份承诺。
- 增加明确的首屏主 CTA（提交图纸/项目询价）和次 CTA（浏览产品），连接现有询价表单锚点及产品列表。
- 保留现有类别、精选产品、共享工厂展示、型材参考、FAQ 和询价表单区块，不整体重做信息架构。
- 复核 “5 categories / 20 catalog references / 2 regional ranges” 统计。若与真实可验证目录不一致或无法帮助采购决策，替换为产品入口或经核实的服务信息；不得添加虚构产能或时效数字。
- 将面向客户的首页介绍文案改为具体、自然的采购与定制价值表达，不保留面向开发者/编辑者的内部说明语气。

### 共享制造场景模块

- 沿用当前 FactoryShowcase 组件、两张批准的本地工厂图片、现有布局及 About 链接。
- 调整标题、说明、按钮和替代文本，使其突出制造场景/制造能力与项目支持，不宣称图片所示场所属于 Lingye。
- 该组件在首页、产品列表、展示页及详情页复用；更新后各页面保持一致。
- 产品详情页独立的数据库工厂图库不在本期重构。其展示所使用的共享翻译键如有归属暗示，应在同一文案审查中改为中性表达，不更改图库数据。

### 全站品牌身份与 SEO 文案

- 扫描并修订指向 Lingye 自身的页面 H1/H2、可见营销文案、title、meta description、Open Graph、Twitter metadata 和默认 HTML metadata 中的 manufacturer/factory-direct/our factory 声明。
- 覆盖首页、About、产品列表、产品详情及相关 SEO landing 模板和全局 title/description 配置；同时检查页脚品牌 slogan、About 公司介绍、产品详情的 “Our Factory” 标题及 “Factory-Direct Pricing”等指向 Lingye 自身的营销说法。保留产品名称、行业说明、买家指南中的通用行业术语。
- 保留现有路由与 SEO landing URL，避免因改写文案造成外链失效。
- 根据实际翻译加载机制同时修订前端 fallback、`frontend/src/utils/titleManager.ts` 页面标题/描述配置和 `backend/translations/frontend_*.json` 资源；支持的翻译 JSON 至少包含英语、西班牙语、葡萄牙语和中文。对标题配置包含的阿拉伯语、印地语也需改正。线上若使用数据库中覆盖文件的文案，需明确记录必须同步更新对应线上翻译记录，部署不得只发布前端构建产物。

## 首页推荐内容顺序

1. 现有工厂轮播首屏：价值主张 + 两个行动入口。
2. 当前首页统计或更直接的产品/服务快捷入口（由数据核验结果决定）。
3. 五类核心产品。
4. 精选产品。
5. 共享制造场景图片模块。
6. 型材表面与应用参考。
7. 买家 FAQ。
8. 询价表单。

不因优化额外增加合作伙伴卡片墙、未验证案例、认证徽章或生产指标。

## 实现边界

- 复用现有 React 路由、翻译 context、metadata hook、共享 FactoryShowcase、InquiryForm 和 Tailwind 设计规范。
- 首屏 CTA 指向现有首页询价锚点或产品列表，不新增后端接口或数据库字段。
- 只编辑与本设计直接相关的首页、共享展示模块、品牌 SEO 文案配置/模板、翻译 JSON 和对应测试；不顺手重写全站 SEO 架构。
- 线上数据库覆盖文案的同步需要列入部署步骤，并以部署后 API/页面核验确认生效。

## 验收标准

- 桌面和移动端首屏均显示清晰标题、可读说明和两个可用行动入口；按钮无重叠，移动端不溢出。
- 三张工厂轮播背景图继续正常切换，内容不再通过轮播宣称自有制造身份。
- 五类产品、精选产品、Factory Showcase、FAQ、询价表单和现有图片仍可正常访问；首屏 CTA 能到达正确目标。
- 首页、About、产品列表、产品详情及相关 SEO landing 页面、页脚和全局 metadata 不再以 Lingye 为主语声称 manufacturer/factory-direct/our factory 或等价表达；通用行业知识及既有 URL 保持。
- 英语、西班牙语、葡萄牙语、中文、阿拉伯语、印地语相关标题/元数据准确且无旧归属说法；API 覆盖文案同步后验证线上响应。
- 增加/更新首页 CTA、metadata、共享工厂模块和身份文案的单元/集成测试；运行相关前端测试和生产构建。
- 部署前后分别记录构建结果、翻译 API 结果、关键页面 metadata 和响应状态；部署仅在实现、测试和页面检查通过后进行。

## 未纳入本期

- 全站技术 SEO 架构重做、prerender/Nginx 修复、站点速度优化、GSC 指标实验。
- 产品规格或数据库产品数据编辑、询价表单字段重构、产品图片替换。
- 改写 SEO landing URL、创建重定向、增加未核实的产能/工厂/客户案例数据。

## 主要风险与处理

- **线上翻译覆盖源码 fallback：** 实施时先确认翻译 API 及生产数据源，发布前后核对 API 返回值；如果需要运营后台手动同步，将其作为发布阻断项。
- **SEO 词与真实身份冲突：** 保留已存在 URL，但页面标题及正文以准确身份为准；不为追逐 manufacturer 词继续作不准确承诺。
- **共享组件影响多页面：** 更新共享组件后运行首页和产品列表/展示/详情相关组件测试，并人工抽查至少一个产品页面。
- **素材可能造成错误归属推断：** 文案保持中性，不伪造拍摄地点、所有权、认证或质检结论；图片本身暂不替换。
